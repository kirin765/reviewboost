발견된 UX 문제들

수정 범위를 확인해주세요. 모두 수정하거나, 원하는 항목만 선택할 수 있습니다.

1

CSS 중복/충돌 정리

버튼·카드·input 스타일이 globals.css 내에서 3번 중복 정의 (라인 ~880, ~2706, ~4478). 뒤쪽 정의가 앞을 덮어씌우면서 예측 불가능한 스타일 발생. → 하나로 통합.

2

네비게이션 active 상태 불명확

현재 active 링크가 연한 파란 배경 + 파란 텍스트. Vercel처럼 → 검정 텍스트 + font-weight 변화로 명확한 현재 위치 표시.

3

버튼 위계 부재

CTA 영역에 Primary + Ghost + Outline 3개가 동시 나열되어 시선 분산. → Primary 하나 강조, 나머지는 명확히 약하게.

4

인증 페이지 장식 과잉

로그인/회원가입 aside에 orb 그라데이션, 카드 애니메이션 등 장식이 많아 오히려 산만. → 깔끔한 브랜드 + 가치 제안 텍스트로 정리.

5

border-radius 불일치

6px, 10px, 12px, 14px, 16px, 999px 등 다양한 radius 혼재. Vercel 기준 → 6px (small), 8px (medium), 12px (large) 3단계로 통일.

6

배경 데코 그라데이션 제거

body::before에 blue+gold radial gradient, dashboard drawer에 blue gradient. → 순백 배경 또는 #fafafa로 통일.

7

Input 스타일 정리

보라빛 border, 큰 radius(16px), inner shadow 등 과잉 장식. → 심플한 1px #eaeaea border, 6px radius, 깔끔한 focus ring.
