# Kakao 로그인 심사 — 개인정보 동의항목 작성본

> ReviewBoost(`reviewboost.co.kr`)의 Kakao 로그인 심사 신청 시 **개인정보 동의항목** 섹션에 입력할 값입니다.

> `docs/kakao-login/signup-screen.png`(PNG, 약 0.1MB — 20MB 이내, 최대 1장)를 업로드하세요.

|------|--------|
| **입력 데이터 라벨** | `회원가입 화면` |

> 첨부 화면(빈 가입 폼)에는 개인정보가 포함되어 있지 않아 마스킹하지 않았습니다.
> (제출 화면에 개인정보가 포함된 경우에만 마스킹 필요)

## 수집 사유

```
카카오 로그인(회원가입) 시 서비스에서 필요한 최소한의 개인정보(이메일)만 수집합니다.
수집된 이메일은 회원 식별 및 로그인 인증, 분석 결과 저장·관리, 결제(구독) 계정 연결, 고객 지원 응대에만 사용하며,
이 외의 개인정보(닉네임·프로필 사진·성별·연령대 등)는 요청하지 않습니다.
```

## 동의 단계 설정 (항목별)

| 필드 | 입력값 |
|------|--------|
| **항목** | `카카오계정(이메일) / account_email` |
| **동의 단계** | `필수 동의` |
| **카카오계정으로 정보 수집 후 제공** | `체크` (사용자에게 값이 없는 경우 카카오계정 정보 입력을 요청하여 수집) |
| **동의 목적** | 아래 코드 블록 참고 |
| **입력 데이터 라벨** | `이메일` |

**동의 목적 (입력값):**

```
카카오 로그인(회원가입) 시 회원 식별 및 로그인 인증을 위해 이메일을 수집하며,
분석 결과 저장·관리, 구독(결제) 계정 연결, 고객 지원 응대 목적으로만 사용합니다.
```

### 선택 근거

- **동의 단계 = 필수 동의**: 로그인/회원가입 시 이메일이 계정 식별자로 필요하므로 필수로 동의를 받습니다
  (실제 OAuth scope는 `account_email` 1건만 요청 — `src/lib/social_auth.ts`).
- **카카오계정으로 정보 수집 후 제공 = 체크(권장)**: 카카오 계정에 이메일이 없는 사용자에게도
  입력을 요청해 항상 실사용 이메일을 확보합니다. 참고로 현재 코드는 이메일이 없으면
  `kakao_{id}@social.reviewboost.co.kr` 합성 이메일로 대체하므로(`resolveSocialEmail`), 체크하지 않아도
  가입 자체는 가능하지만 실사용 이메일 확보 차원에서 체크를 권장합니다.
- **입력 데이터 라벨 = 이메일**: 동의 화면에 사용자에게 보여줄 라벨입니다.
  회원가입 폼의 실제 입력 라벨("이메일 주소")과 맞추고 싶다면 `이메일 주소`로 입력해도 무방합니다.

## 참고 (심사 제출 전 확인 사항)

- **카카오 동의 항목**: 실제 OAuth scope는 `account_email`(이메일) 1건만 요청합니다.
  (`src/lib/social_auth.ts` — kakao scope: `account_email`)
- **개인정보 처리방침**(`/privacy`)에 수집 항목(이름·이메일·계정 정보·결제 정보·업로드 리뷰 데이터)과
  보호책임자(개인정보 보호책임자: 김기완, kwan765@naver.com)가 명시되어 있습니다.
- **회원가입 화면 캡처**: 라이브 사이트(`https://reviewboost.co.kr/signup`) 기준 최신 화면입니다.
