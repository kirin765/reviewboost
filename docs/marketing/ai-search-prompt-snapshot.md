# ReviewBoost AI 검색 프롬프트 스냅샷 워크시트

- 목적: ReviewBoost가 AI 답변에서 어떻게 등장·추천·인용되는지 **측정 먼저** 기록하고, 준비도(Readiness) 갭에 가설을 부여한다.
- 근거: Aleyda Solis 3 Layer Framework(2026-08-26) + AI Search Optimization Checklist(2026-09). Presence 5 KPI 사용.
- 대상: ChatGPT, Google AI 검색(AI Overviews / AI Mode), Gemini, Perplexity, Claude.
- 주기: **월 1회**. 각 프롬프트를 고정 시간창(24~72시간) 안에서 3~5회 실행하고 대표 결과를 남긴다.

## 실행 규칙

1. 프롬프트는 수정하지 않고 그대로 입력한다(비교 가능성 유지).
2. 새 세션에서 실행하고, 로그인·개인화 영향은 같은 조건으로 맞춘다.
3. 각 실행마다 실제 인용 출처 URL을 기록한다. 인용이 자사면 자사, 아니면 경쟁·3자 출처를 적는다.
4. 판정은 추정하지 않는다. 못 본 항목은 `?`(미확인)로 둔다.
5. 매달 같은 파일을 복제해 `YYYY-MM` 스냅샷으로 보관한다.

## 준비도(Readiness) 가설 매핑

각 미등장/부정확 항목을 아래 특성 하나에 매핑하고, 오너와 검증 계획을 적는다.

- **접근(accessible)** / **추출(extractable)**: 페이지가 AI 크롤러에 읽히는가
- **유용(useful)** / **최신(fresh)**: 과제를 완결하는가, 갱신됐는가
- **차별(differentiated)**: 1차 근거·고유 데이터가 있는가
- **인식(recognizable)** / **일관(consistent)**: 엔터티·상업정보가 명확·일치하는가
- **교차검증(corroborated)** / **신뢰(credible)**: 3자 출처가 뒷받침하는가
- **거래가능(transactable)**: 다음 행동(설치·가격·결제)이 연결되는가

우선순위: `Severity × Importance / Effort`.

## 판정·금지

- 인용 카운트를 트래픽 대리값으로 쓰지 않는다 (`AI citations ≠ AI traffic`).
- 순위·매출 인과를 측정 없이 단정하지 않는다.
- 브랜드 자사 불만·오류는 실제 화면/공식 문서로 확인한 것만 적는다.
