2. 메뉴별 상세 설명과 화면

2.1 회원가입 / 로그인 네이버 로그인 적용 화면

이메일·비밀번호 가입 또는 네이버/카카오 로그인. 네이버 로그인 시 이메일 1건만 요청·수집하며, 로그인 인증 수단으로만 사용합니다.

2.2 리뷰 분석 (대시보드)

CSV/XLSX 업로드 → 컬럼 매핑(리뷰 텍스트·별점·날짜) → 분석 실행. 감정 분류(긍정/부정), 카테고리 분류(배송/품질/사용성/CS/가격/기타), 부정 키워드 TOP10, 우선순위 점수(0~100), 최근성 분석, PDF 리포트를 제공합니다.

※ 홈(서비스 소개), 대시보드 업로드 화면, 분석 결과 상세, 히스토리, 요금제 페이지는 라이브 사이트(https://reviewboost.co.kr)에서 캡처 후 이 위치에 이미지로 추가하세요. (샘플 데이터: https://reviewboost.co.kr/sample.csv 로 무료 분석 화면 재현 가능)

2.3 Chrome 확장 프로그램 「ReviewBoost 리뷰 수집기」 스마트스토어 리뷰 수집

사용자가 보고 있는 쿠팡·스마트스토어 상품 페이지의 공개 리뷰를 수집해 엑셀/CSV로 내보내거나, 사용자가 선택한 경우에만 ReviewBoost 분석으로 전송합니다.

3. '익스텐션 플랜 — 스마트스토어 리뷰 수집 무제한' 상세

3.1 데이터 출처

  • 사용자(판매자)가 브라우저에서 직접 열어 본 스마트스토어(smartstore.naver.com) 및 브랜드스토어(brand.naver.com) 상품 상세 페이지에 공개 표시된 리뷰만 대상으로 합니다.
  • 수집 항목: 리뷰 본문 텍스트, 별점, 작성일, 옵션, 도움됨 수, 사진/동영상 URL, 마스킹된 작성자 ID(예: dj****) — 상품 페이지에 공개 표시된 정보만 해당하며, 비공개 정보·개인정보(성명·연락처·주소 등)는 수집하지 않습니다.

3.2 수집 방식

  • 확장 프로그램(Chrome MV3, activeTab 권한)이 사용자의 브라우저 세션 안에서 동작하며, 사용자가 보고 있는 상품 페이지에 표시되는 것과 동일한 공개 리뷰 정보를 읽어 사용자에게 보여줍니다.
  • 사용자가 상품 페이지에서 확장 프로그램 아이콘 클릭 → '리뷰 수집' 버튼을 누른 경우에만, 해당 활성 탭의 상품 1건에 대해 수집이 실행됩니다.
  • 서버가 네이버에 직접 요청하는 방식이 아니며, 사용자의 네이버 계정·비밀번호·쿠키 등 인증 정보에 접근하지 않습니다.
  • 수집 한도: 무료 플랜 하루 50개 / 익스텐션 플랜 구독 시 무제한 (월 4,900원, Basic·Pro 구독 시 포함).

3.3 활용 목적

  • ① 판매자 본인(또는 확인 중인) 상품 리뷰의 엑셀/CSV 백업·정리 (스마트스토어 판매자센터 공식 리뷰 엑셀 25열 폼: 별점·제목·리뷰내용·작성자·작성일·도움됨·포토/영상 등).
  • ② 사용자가 'ReviewBoost로 분석'을 선택한 경우에만 리뷰 텍스트를 서버로 전송하여 AI 분석 리포트 생성 — 부정 리뷰 조기 발견, 불만 카테고리 파악(배송/품질/가격/사용성/CS/기타), 대응 우선순위 결정, 개선 제안 도출.
  • ③ 부정 리뷰 고객 응대 지원.
  • 수집 데이터는 제3자에게 판매·공유하지 않으며 광고 목적으로 사용하지 않습니다. 엑셀/CSV 다운로드만 하는 경우 어떤 데이터도 외부로 전송되지 않습니다.
요금제 기능임을 명시: '스마트스토어 리뷰 수집 무제한'은 네이버 API 기능이 아니라, ReviewBoost 자체 확장 프로그램의 일일 수집 한도를 없애주는 유료 요금제(익스텐션 플랜)의 기능입니다. 리뷰 수집·분석 기능 전반은 네이버 로그인(네이버 로그인 API)을 사용하지 않으며, 네이버 로그인은 회원가입/로그인 인증 수단으로만 사용됩니다. 본 서비스는 쿠팡·네이버와 제휴 관계가 없는 독립 도구입니다.

5. 네이버 로그인 활용 범위 및 준수 사항

  • 네이버 로그인은 회원가입/로그인 인증 수단으로만 사용하며, OAuth 요청 항목은 이메일 1건(필수)입니다.
  • 로그인으로 얻은 이메일은 회원 식별, 분석 결과 저장·관리, 구독(결제) 계정 연결, 고객 지원 응대에만 사용합니다.
  • 스마트스토어 리뷰 수집·분석은 네이버 로그인과 분리되어 있으며, 공개 리뷰 데이터만 사용자 개시 행위(버튼 클릭)로 처리됩니다.
  • 확장 프로그램은 원격 코드를 실행하지 않으며, 모든 로직이 패키지에 포함되어 있습니다. 수집 데이터 전송은 사용자가 명시적으로 선택한 경우에만 이뤄집니다.
  • 수집·처리 항목과 목적·보관 기간·문의처는 개인정보처리방침(https://reviewboost.co.kr/privacy)에 명시되어 있으며, 별도 문의는 kwan765@naver.com으로 가능합니다.
