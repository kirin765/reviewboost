### 3. '익스텐션 플랜 — 스마트스토어 리뷰 수집 무제한' 상세

- **요금제 기능임을 명시**: '스마트스토어 리뷰 수집 무제한'은 네이버 API 기능이 아니라, ReviewBoost
  자체의 Chrome 확장 프로그램에서 **일일 수집 한도 없이** 리뷰를 수집할 수 있게 하는 유료 요금제
  (익스텐션 플랜, 월 4,900원)의 기능입니다. 무료 플랜은 하루 50개로 제한되며, 유료 구독 시
  무제한으로 전환됩니다.
- **데이터 출처**: 사용자가 브라우저에서 직접 열어 본 스마트스토어(`smartstore.naver.com`) 및
  브랜드스토어(`brand.naver.com`) **상품 상세 페이지에 공개 표시된 리뷰**만 대상.
  수집 항목: 리뷰 본문, 별점, 작성일, 옵션, 도움됨 수, 사진/동영상 URL, **마스킹된 작성자 ID**
  (예: `dj****` — 전체 ID 불가).
- **수집 방식**: 사용자 브라우저 세션 안에서 동작하는 확장 프로그램(Chrome MV3, `activeTab` 권한)이
  사용자가 보고 있는 상품 페이지와 동일한 공개 리뷰 정보를 읽어 사용자에게 보여줍니다. 사용자가
  '리뷰 수집' 버튼을 누른 경우에만, 활성 탭의 상품 1건 단위로 수집됩니다. 서버에서 네이버에 직접
  요청하는 방식이 아니며, 로그인 계정·비밀번호·쿠키 등 인증 정보에는 접근하지 않습니다.
- **활용 목적**: ① 판매자 본인(또는 확인 중인) 상품 리뷰의 엑셀/CSV 백업·정리(스마트스토어
  판매자센터 공식 리뷰 엑셀 25열 폼) ② 사용자가 선택한 경우에만 ReviewBoost AI 분석으로 전송해
  리포트 생성 — 부정 리뷰 감지, 불만 카테고리 파악, 대응 우선순위 결정, 개선 제안 도출 ③ 부정
  리뷰 고객 응대. 제3자 판매·공유·광고 목적 미사용.
- **쿠팡·네이버와의 관계**: 본 서비스는 쿠팡·네이버와 제휴 관계가 없는 독립 도구이며, 공개 표시된
  리뷰 데이터를 사용자 본인의 브라우저에서 처리하는 방식입니다.

### 4. 네이버 로그인 활용 범위

- 네이버 로그인은 **회원가입/로그인 인증 수단으로만** 사용합니다 (`/login`, `/signup`).
- OAuth 요청 항목: `email` 1건 (필수). 이름 등 추가 항목은 활용하지 않습니다.
- 로그인으로 얻은 이메일은 회원 식별, 분석 결과 저장·관리, 구독(결제) 계정 연결, 고객 지원 응대에만
  사용합니다.
- 스마트스토어 리뷰 수집·분석 기능은 네이버 로그인과 완전히 분리되어 있으며, 네이버 로그인 API를
  사용하지 않습니다.
- 개인정보처리방침: https://reviewboost.co.kr/privacy (수집 항목·처리 목적·보관 기간·문의처 명시)

### 5. 준수 사항

- 스마트스토어 리뷰 수집은 **판매자가 자신이 운영(또는 확인)하는 상품의 공개 리뷰**를 대상으로 하며,
  개인정보(성명·연락처·주소·금융정보 등)는 수집하지 않습니다.
- 수집된 리뷰 데이터는 사용자 본인의 분석 용도로만 사용되며, 공유·전송은 사용자가 명시적으로
  선택한 경우(분석 버튼 클릭)에만 이뤄집니다.
- 확장 프로그램은 원격 코드를 실행하지 않으며, 모든 로직이 패키지에 포함되어 있습니다.

## C. 제출 절차

1. [네이버 개발자센터](https://developers.naver.com/apps) → 'Review Boost' 애플리케이션 →
   **검수 신청/검수 이력** 페이지 접속.
2. **"소명 내용 입력"** 란에 위 **A** 섹션의 텍스트를 붙여넣기 (개인정보 포함 문구 없음 확인).
3. **파일첨부**: `docs/naver-login/서비스-소개-자료.pdf` (7페이지 A4, 1.5MB — 5MB 한도 내) 선택.
   웹 앱 화면 캡처를 추가하고 싶다면 `서비스-소개-자료.html`에 이미지 추가 후
   `node scripts/make-naver-intro-pdf.cjs` 로 재생성.
4. 검수 가이드([네이버 로그인 검수 안내](https://developers.naver.com/docs/login/verify/verify.md))의
   요구사항과 대조 후 **재검수 요청**.
