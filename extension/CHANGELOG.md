# ReviewBoost 리뷰 수집기 — 변경 이력 (Changelog)

## 1.6.1 (2026-10-14) — 리뷰 수집 복구 및 별점 리뷰 선택

- SSG닷컴 리뷰 수집 복구 — 사이트가 리뷰 항목 래퍼를 li에서 div로 바꿔 0건으로 끝나던 문제를 수정했습니다.
- 별점만 남긴 리뷰(본문 없음)를 모든 쇼핑몰에서 수집·엑셀/CSV 내보내기에 포함합니다(스마트스토어·무신사·29CM·G마켓·옥션·11번가·SSG·오늘의집·컬리·올리브영). 텍스트 분석 전송에는 여전히 본문이 있는 리뷰만 사용합니다.
- 팝업에 ‘별점만 있는 리뷰도 포함’ 체크박스를 추가했습니다 — 끄면 본문이 있는 리뷰만 수집·다운로드하고, 설정은 다음 수집에도 유지됩니다(기본 켜짐).

## 1.6.0 (2026-10-14) — 톡스토어(카카오톡 스토어) 리뷰 수집 지원

- 톡스토어(store.kakao.com) 상품의 공개 리뷰를 수집해 엑셀/CSV로 내보내기 지원 — 지원 쇼핑몰 총 12곳.
- 톡스토어 별점은 4점 척도(매우 만족~매우 아쉬움)라 공용 5점 척도로 변환해 내보냅니다 (매우 만족 4→5, 만족 3→4, 아쉬움 2→2, 매우 아쉬움 1→1).
- 리뷰 ID 기준 중복 제거, 표시 총수 대비 일부 수집 안내 등 기존 수집 안전장치 동일 적용.
- 일부 수집 안내가 쿠팡 이름을 고정 표시하던 것을 해당 플랫폼 이름으로 바꿉니다.
- 쿠팡 보조 수집(최신순·별점별)이 도중에 차단돼도 그때까지 모은 리뷰는 유지하고 일부 수집 안내로 마무리합니다.
- 검증: 실상품(표시 7,943개)에서 어댑터로 1,200건 라이브 수집 — 0-based 페이지 순회·중복 제거·별점 변환·KST 작성일 변환 확인. 옥션·11번가는 본문 없는 별점만 리뷰가 실제로 존재함을 라이브로 확인(옥션 33건 중 19건).

## 1.5.3 (2026-10-14) — 쿠팡 리뷰 수집 건수 수정

- 쿠팡의 별점만 있는 리뷰와 제목만 있는 리뷰도 엑셀/CSV 다운로드에 포함합니다.
- 글이 있는 리뷰 수와 다운로드 건수를 구분하고, 텍스트 분석에는 글이 있는 리뷰만 전달합니다.
- 요청 수량에 도달하기 전에 수집이 끝나면 일부 수집 안내와 쿠팡 표시 총수를 보여 줍니다. 최근 기록을 복원해도 안내를 유지합니다.
- 쿠팡 기본 정렬이 중간에 끝나면 최신순과 별점별 보기에서 누락 리뷰를 추가 수집하고, 리뷰 ID로 중복을 제거합니다. 요청 건수에 도달하면 즉시 멈춥니다.
- 검증 사례: 표시 1,667개 상품에서 고유 리뷰 1,667건을 확인하고, 동일 응답을 수정된 수집기에 재생하여 엑셀/CSV 1,667건과 글이 있는 리뷰 502건을 검증했습니다.

## v1.4.1 (2026-08-29) — Chrome Web Store · Edge · 웨일 제출

새로운 기능 / 변경사항

- 리뷰 **이미지 URL 수집** — 쿠팡·스마트스토어 사진 리뷰의 이미지 주소를 함께 수집합니다.
- 내보내기 **스마트스토어 판매자센터 공식 리뷰 엑셀(25열) 폼** 채택 — 별점·리뷰내용·작성자·작성일·도움됨·**포토/영상** 등의 열을 공식 양식 그대로 내보냅니다.
- **유료 플랜 무제한** — 익스텐션 플랜 구독자는 일일 수집 한도 없이 수집할 수 있습니다 (무료 플랜은 하루 50개 유지).
- 안정성 개선 — 브랜드스토어(묶음상품) 리뷰 수집 지원, 최근 기록 5건 표시.
- **CS 문의 탭 추가** — 팝업에서 바로 문의 유형·이메일·내용을 입력해 ReviewBoost 1:1 문의로 접수 (평균 1~2일 내 이메일 답변). 문의 내용만 전송되며, 수집 데이터는 전송되지 않습니다.

이전 버전 대비 주요 변화

- (v1.3.x 대비) 이미지 URL 수집, 공식 엑셀 폼, 유료 무제한, 브랜드스토어 지원, CS 문의 탭
