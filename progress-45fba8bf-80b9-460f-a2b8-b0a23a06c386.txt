## Codebase Patterns
- For SQL migrations that must be re-runnable and safe on legacy data, pair `ADD COLUMN IF NOT EXISTS` with conditional constraint hardening in a `DO $$` block instead of unconditional `ALTER COLUMN ... SET NOT NULL`.
