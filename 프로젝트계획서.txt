

# 프로젝트명

**ReviewBoost (가칭)**
– 스마트스토어/쿠팡 판매자용 매출 개선 리뷰 분석 SaaS

---

# 1. 문제 정의 (Problem)

### 타겟

* 월 매출 300만원~5천만원 사이 스마트스토어/쿠팡 판매자
* 광고비를 쓰고 있지만 전환율 개선에 어려움 겪는 판매자

### 핵심 문제

1. 리뷰가 많아도 읽고 정리하기 어려움
2. 별점 하락 원인을 구조적으로 파악 못함
3. 상세페이지 개선 방향을 데이터 기반으로 못 잡음
4. 경쟁사 리뷰 분석은 거의 안 함

### 현재 해결 방식

* 수동으로 리뷰 읽음
* 컨설팅 업체 의존 (비쌈)
* 감으로 상세페이지 수정

→ 비효율 + 데이터 기반 아님

---

# 2. 해결책 (Solution)

### 한 문장 정의

“리뷰를 업로드하면 매출 개선 포인트와 수정 문구를 자동으로 제공하는 SaaS”

---

## MVP 기능 정의

### 1) 리뷰 업로드

* CSV 업로드 (플랫폼 상관 없음)
* 리뷰 텍스트 + 별점만 있어도 가능

### 2) 자동 분석

* 긍정/부정 비율
* 부정 키워드 TOP10
* 문제 카테고리 분류

  * 배송
  * 품질
  * 가격
  * 사용성
  * CS

### 3) 개선 제안 생성

* 상세페이지 수정 문구 자동 생성
* 고객 불만 대응 문구 생성
* FAQ 추천

### 4) 요약 리포트

* PDF 다운로드
* 개선 우선순위 점수화

---

# 3. 차별화 전략

기존 분석 툴은 “데이터”만 보여줌
우리는 “매출 개선 행동”까지 제공

포지셔닝:
❌ 리뷰 분석 도구
✅ 매출 전환율 개선 리포트 SaaS

---

# 4. 시장 가설

### 시장 규모 (가정 기반)

* 스마트스토어 판매자 약 50만+
* 실제 활동 판매자 10만 이상
* 그 중 유료 SaaS 지불 가능 5~10%

목표 시장 = 5,000~10,000명

---

# 5. 수익 모델

### 요금제

* 무료: 1회 분석
* Basic: 월 49,000원
* Pro: 월 89,000원 (경쟁사 분석 포함 – 2단계)

### 목표

1차 목표: 100명 확보
→ 월 490만원

2차 목표: 500명
→ 월 2,450만원

# 6. 개발 계획

## 기술 스택

Frontend:

* Next.js

Backend:

* Supabase

AI:

* OpenAI API (GPT-4o-mini 등 비용 최적 모델)

PDF:

* Puppeteer or server-side generator

---

## 개발 단계 (8주 계획)

### 1~2주

* UI 기본 구조
* 회원가입 / 로그인
* 파일 업로드

### 3~4주

* 리뷰 파싱
* 감성 분석 로직
* 키워드 추출

### 5~6주

* LLM 기반 개선 제안 생성
* 점수화 로직 설계

### 7주

* PDF 리포트 생성

### 8주

* 결제 연동 (Stripe)
* 베타 테스트

# 7. 마케팅 계획

## 1단계 (무료 유입 확보)

채널:

* 네이버 판매자 카페
* 오픈채팅방
* 스마트스토어 교육 강사

전략:
“무료 매출 개선 리포트 1회 제공”

목표:
30명 무료 사용자 확보
→ 후기 10개 확보

---

## 2단계 (유료 전환)

* 무료 사용자 중 상위 20% 집중 타겟
* 전환율 목표: 20%

30명 → 6명 유료 전환

---

# 8. 비용 구조

손익분기점:
